# Archived sessions

Every finished 尾盘选股 session, kept as static files: `<date>.md` (readable here on GitHub), `<date>.csv` (ranked list) and `<date>.parquet` + `.json` (everything the app needs). `volumes/` holds each session's closing volumes for the opening-auction queries. The newest 5 sessions keep every candidate; older ones keep the ranked list and the closest stocks, up to 250 sessions. 5 volume books are kept.

The Strategy lab's scorecards (backtest and live record) are in [lab/README.md](lab/README.md). The 16:00 after-close screen (收盘选股) is in `cn/screens/<date>.md`.
