# Archived sessions

Every finished 尾盘选股 session, kept as static files: `<date>.md` (readable here on GitHub), `<date>.csv` (ranked list) and `<date>.parquet` + `.json` (everything the app needs). `volumes/` holds each session's closing volumes for the opening-auction queries. Only the newest 4 sessions and 5 volume books are kept: the daily job drops older ones.

The Strategy lab's scorecards (backtest and live record) are in [lab/README.md](lab/README.md). The 16:00 after-close screen (收盘选股) is in `cn/screens/<date>.md`.
